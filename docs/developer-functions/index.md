# Developer Functions

System Monitor includes various features that are available for experienced operators. These come under the following categories:

- [Diagnostics](diagnostics.md) - Provides information for embedded software developers and can be useful for troubleshooting the operation of the ECU and of System Monitor itself.
- [System Log](system-log.md) - Files of errors and events that occur during the operation of System Monitor.
- [Productivity Tools](productivity-tools/index.md) - Allows repetitive processes to be automated also provides links with other applications.
- [Settings](../using-system-monitor/settings.md) - Changes various System Monitor configuration settings.
