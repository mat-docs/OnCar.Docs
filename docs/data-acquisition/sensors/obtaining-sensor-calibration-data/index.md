# Obtaining Sensor Calibration Data

Sensors and actuators supplied by Motion Applied are tested at many points in their operating range to produce a calibration table. This is saved as a file in ASCII format with the extension .dat. The file is shipped with the sensor.

!!! warning
    - Do not amend the sensor calibration database while System Monitor is running.
    - Do not edit the contents of the .dat files.

For calibration data, contact [Motion Applied](../../../technical-support/motion-applied.md) through the support portal at [https://portal.motionapplied.com/](https://portal.motionapplied.com/).
