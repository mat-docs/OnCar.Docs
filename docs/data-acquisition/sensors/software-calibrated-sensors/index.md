# Software Calibrated Sensors

The output of many sensors is inherently non-linear (the output is not proportional to the input). A linear output is often achieved by limiting the range of the sensor and by adding complex compensation circuitry. This reduces the usefulness of the sensor and increases its cost.

An alternative is to accept the non-linear output and use the computing power of the ECU to compensate by referring to a look-up table. This is known as Software Calibration and it is supported by all TAGtronic control systems and sensors. This method lets you use simple, robust and relatively low-cost sensors while obtaining the best possible accuracy.
