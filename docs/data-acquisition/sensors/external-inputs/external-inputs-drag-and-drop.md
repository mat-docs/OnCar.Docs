# External Inputs - Drag and Drop

The tree in the External Inputs dialog box displays the configuration of sensor inputs to the unit. After the system has been configured, it can be modified by dragging items to different locations in the tree. The items that can be moved in this way are:

- [Nodes](external-inputs-selecting-a-node.md)
- [Interface Cards](external-inputs-sn-6-interface-cards.md)
- [Individual Sensors](external-inputs-adding-a-sensor.md)

An item can only be dropped on a suitable location. If a suitable location is not found, the move is cancelled. Ensure that the target location is visible (that is, the bus and node are expanded) before you drag an item. The tree scrolls if you move the cursor above or below it.

Any item can be dropped in the **Spare Items Pool**, a temporary location for work in progress or alternative configurations. The Spare Items Pool can hold any number of copies of an item, which can be modified as required.

Items can also be moved or copied using the **Cut**, **Copy** and **Paste** commands on the context menu.

**See also:** [External Inputs Configuration](external-inputs-configuration.md)
