# Data Acquisition

System Monitor includes tools to configure the way that an ECU (or other data logging device) acquires and saves data. The tools are grouped in two categories:

- [Logging](logging/index.md) - The logging configuration tools allow you to set up the ECU to send data to System Monitor, to store it for later uploading or to transmit it by telemetry. The Logging menu also contains the CAN Configuration tools.
- [Sensors](sensors/index.md) - The sensor tools allow you to set up the calibration of the sensors attached to the ECU and to configure [Sensor Nodes](../hardware/sensor-bus.md).

**See also:** [Data Display](../data-display/index.md)
