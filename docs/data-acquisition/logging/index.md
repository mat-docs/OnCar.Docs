# Logging

Logging is the process by which data is acquired by an ECU and transferred to an analysis system. The logged data is obtained from [Measurement Parameters](../../using-system-monitor/parameters/measurement-parameters.md).

System Monitor has the following facilities to configure the way that the ECU logs data:

- [Live Logging](live-logging/index.md) - Send data directly to System Monitor, via a wirelink, without storing it in the ECU. Also includes facilities to create a Session for analysis by [ATLAS](../../technical-support/atlas.md).
- [Remote Logging](remote-logging/index.md) - Store data in DATALab Memory.
- [Burst Logging](burst-logging/index.md) - Store data in Burst Memory, which is also used for Wide Band Telemetry.

The [Logging Menu](../../using-system-monitor/menus/logging-menu.md) also gives access to [Remote Configuration Compare](remote-configuration-compare/index.md), [CAN Configuration](can-configuration/can-configuration-dialog-box/index.md) and the [Input Signal Configuration Tool](../sensors/external-inputs/input-signal-configuration-tool.md).
