# Driver push button panel

A driver push button fitted to the dash or steering wheel can be configured to clear the ECU data logging memory or for use as a trigger condition.

The options are as follows:

- **Button on clears logged data** - When the driver push button is pressed, the ECU data logging memory is cleared.
- **Button on used as trigger condition** - The driver push button is used as a trigger condition.
- **Button disabled** - The driver push button has no effect.

!!! note
    The [Channel Trigger](../channel-trigger.md) dialog box no longer has a Driver push button condition. Its trigger conditions are On data, Ignition on, Lap trigger, External Trigger and No condition.

**See also:** [Remote Logging - Channel Overview tab](channel-overview-tab.md); [Remote Logging - Channel Trigger](../channel-trigger.md)
