# Live Logging - Automatic Recording

Make an automatic recording:

1. On the [Trigger Timing tab](trigger-timing-tab.md), select **Start logging** or **Stop logging** as the Mode.
2. Close the Configure Live Logging dialog box.
3. Select **Logging** > **Trigger Enable**.
4. Select **ECU** > **On Line** to put the ECU On-Line.
5. With **Start logging**, recording starts when the trigger condition is TRUE and stops when the Logging Time has elapsed. With **Stop logging**, start recording with **Logging** > **Recording**; recording stops when the trigger condition is TRUE or when the Logging Time has elapsed.

Recording can also be stopped by selecting **Logging** > **Recording** or by taking the ECU Off-Line.

**See also:** [Live Logging - Recording](recording.md)
