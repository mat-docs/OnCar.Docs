# Live Logging - Recording

Live Logging can record a Session in two ways:

- **Manual** - Manual is selected as the Mode on the [Trigger Timing tab](trigger-timing-tab.md). Select **Logging** > **Recording** to start recording, and select it again to stop.
- **[Automatic](automatic-recording.md)** - Start logging or Stop logging is selected as the Mode on the Trigger Timing tab, and the trigger is enabled with **Logging** > **Trigger Enable**.

**Logging** > **Recording** is available while the ECU is On-Line and the Mode is Manual or Stop logging, and at any time while a Session is being recorded.

The [Status Bar](../../../using-system-monitor/tool-and-information-bars/status-bar.md) indicates the status of recording as follows:

- **Recording OFF** - The [Session](../sessions-and-telemetry.md) is not being recorded.
- **Recording ON** - The Session is being recorded.
- **Trigger pending** - Waiting for the trigger condition to become TRUE.
