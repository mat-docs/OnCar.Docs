# Data Wizard - Selecting Parameters

By default, the Report View window and the Candidate Data Version window show all the parameters that pass the Parameter Mask.

Parameters can be selected to limit the number of parameters that are shown in the window.

**Select parameters:**

Open the [Select Parameters](../../using-system-monitor/parameters/selecting-parameters/selecting-multiple-parameters.md) dialog box using the controls in:

- the [Standard Tool Bar](../../using-system-monitor/tool-and-information-bars/standard-tool-bar.md)
- the [Data Wizard Menu](../../using-system-monitor/menus/data-wizard-menu.md) (**Select Parameters**)
- the [Data Wizard - Window Menu](data-wizard-window-menu.md)

**Remove parameters from a Report View or Candidate Data Version window:**

- Select a parameter or group of parameters and press the Delete key. The changes are reflected in the Select Parameters dialog box.

The list of selected parameters can be saved and reloaded with **Save Parameter Set** and **Load Parameter Set** on the **DataWizard** menu. Recently used parameter sets are listed under **Recent Parameter Sets**.

!!! note
    Parameters can be copied and pasted to and from the Parameter Explorer or other windows.
