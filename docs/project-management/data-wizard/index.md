# Data Wizard

Data Wizard compares the contents of the Edit Buffer with one or more previously created Data Versions, known as Candidate Data Versions. Using the Merge facility, parameters in the current Data Version can be overwritten with those in the Candidate Data Versions.

Data Wizard features the following tools, all available from the **DataWizard** menu:

- [Compare/Merge Tool](compare-merge-tool.md) (**Compare / Merge Tool**) - Shows parameters from up to two Candidate Data Versions and compares them with the contents of the Edit Buffer.
- [Candidate Version Window](data-wizard-candidate-version.md) (**Open Data Version**) - Shows parameters in each Candidate Data Version and compares them with the contents of the Edit Buffer.
- [Report View Window](data-wizard-report-view.md) (**Report View**) - Shows parameters in the Edit Buffer and compares them with the current Data Version.

The **DataWizard** menu also has:

- **Open Any Data Version** - Allows a Data Version to be opened from outside the active Customer Base.
- **Save Parameter Set**, **Load Parameter Set** and **Recent Parameter Sets** - Save and reload the list of selected parameters.
- **Compare with ECU** - Compares the Edit Buffer of an application with the data uploaded from the ECU. From this view, the uploaded data can be saved with **Save As Data Version**.
- **Print Setup** - Sets up the format of Data Wizard reports.
