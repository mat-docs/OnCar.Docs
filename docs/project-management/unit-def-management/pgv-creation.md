# PGV Creation

When [creating a PGV from the command line](../program-and-data-versions/creating-a-program-version-command-line.md), the **/location** option specifies the base folder in which to create the PGV. If Customer Bases are set up, the **/customer** option still works, even if the Advanced Setting is set to use [Unit.Def](file-management.md) files.

When a PGV is created with **File** > **New** > **Program Version** and Unit.Def configuration is enabled, a folder selection dialog box (**Select project BASE location for new PGV.**) opens first to define the base location of the new PGV.
