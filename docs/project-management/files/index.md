# Files

System Monitor uses several different files in the following categories:

- [ECU Files](types-of-files/ecu-files.md) - Embedded software files distributed by the customer support team or by the ECU manufacturer. Not part of System Monitor.
- [Program and Data Version Files](types-of-files/program-and-data-version-files.md) - The System Monitor working files, generated by System Monitor from the ECU files. See [Program and Data Versions](../program-and-data-versions/index.md).
- [Project Files](types-of-files/project-files.md) - Files generated by System Monitor to store its own configurations.
