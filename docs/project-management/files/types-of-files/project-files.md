# Project Files

When a Multi-Application Base is set up, the following directory structure is used:

| Directory | Description |
|---|---|
| \\*MultiAppName*\\ | **Multi-Application Base Directory** - The top-level directory that contains all Project files. |
| \\*MultiAppName*\\*CustBaseName*\\ | **Customer Base Directory** - A sub-directory of the Multi-Application Base Directory. There is a Customer Base directory for each Application. |

When a new Program Version is created, the following structure is created in the Customer Base Directory:

| Directory / file | Description |
|---|---|
| \\*version*\\ | A sub-directory of the Customer Base Directory, which contains the Program and Data Version files. Its name is the version string embedded in the ASAP file. The ASAP file is linked to the Customer Base by the ASAP project name. |
| *version*.pgv | The Program Version file. |
| *version*000.dtv | The Base Data Version file. |

When a Project is created, the project file is placed in the selected folder (normally the Multi-Application Base Directory), and the following sub-directories are created in that folder if they do not already exist:

| Directory / file | Description |
|---|---|
| *ProjectName*.prj | The project file. *ProjectName* is set on the Project page when [Creating a Project](../../projects/creating-a-project/stage-1-define-project.md). |
| \Desktops\ | The default location for Desktop files. The Desktop for the new project (for example *ProjectName*.dtp) is placed here. |
| \LogCfgs\ | The default location for the Logging Configuration files (live, burst and remote), External Inputs Configuration files and CAN Configuration files. |
| \Sessions\ | The default location for all Session files recorded by Live Logging. |
| \Virtuals\ | The default location for Virtual Parameter files. |
| \Work\ | The default location for the Event Logs. |
| \SenSets\ | The default location for Sensor Set files generated by the Sensors & Actuators tool. |
| \PotBoard\ | The default location for Pot Board Configuration files. |
| \HistReps\ | The default location for History Report files. |

When [Unit.Def](../../unit-def-management/file-management.md) configuration is used, some of these locations can be changed in the Unit.Def file.
