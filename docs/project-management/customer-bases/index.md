# Customer Base

The Customer Base links the ASAP project to the file directories used by System Monitor and only allows work to be done on files that are associated with the ECU identified by the ASAP project.

The Customer Bases are associated with a Project by means of the Multi-Application Base for that Project. The files in a Customer Base define an Application within the Project.

Customer Bases can be added, removed and edited in the Select Active Multi-Application Base dialog box (see [Multi-Application Base](multi-application-base.md)).

!!! note
    Customer Bases are not used when the Advanced Setting **Enable Unit.Def configuration (Y/N)** is set to Y. See [Unit.Def Management](../unit-def-management/introduction.md).
