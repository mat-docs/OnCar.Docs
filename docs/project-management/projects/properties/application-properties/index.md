# Application Properties

Application Properties can be used to view information about the files used by an Application.

Each Application in the project is listed on the **File** > **Properties** submenu. Selecting an Application opens the Application Properties dialog box for that application.

The dialog box has the following tabs. The tab titles start with the application name.

- [Program Version](application-properties-program-version-tab.md) - Displays information about the Program Version loaded into the Application.
- [Data Version](application-properties-data-version-tab.md) - Displays information about the Data Version currently being used by the Application.
- [Memory Layout](application-properties-memory-layout.md) - Displays the memory locations currently being used by the Application.
- [Unlock List Management](application-properties-unlock-list-management.md) - Manages the Unlock List of the Application.
