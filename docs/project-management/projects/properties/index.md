# Properties

When a Project is open, Properties can be used to view information about the files used by the project and its applications.

To access the Properties commands, select **File** > **Properties**. The options are:

- **Project** - Opens the [Project Properties](project-properties.md) dialog box, which displays information about the files used by the project.
- **Connections** - Opens the Project Properties dialog box at the [Connections tab](connections.md). Also available as **ECU** > **Connections**.
- **Application names** - Each Application in the project is listed. Selecting a name opens the [Application Properties](application-properties/index.md) dialog box, which displays information about the files used by that application.

**See also:** [Project Properties](project-properties.md); [Applications](../../applications.md); [Parameter Properties](../../../using-system-monitor/parameters/parameter-properties/index.md)
