# Project Properties

Project Properties displays information about the files used by the project.

To open the **Project Properties** dialog box, select **File** > **Properties** > **Project**.

The dialog box has a tab for each file loaded in the project:

| Tab | Description |
|---|---|
| **Project** | Information about the Project file. |
| **Desktop** | Information about the Desktop file. |
| **Live Logging Config** | Information about the Live Logging Configuration file. |
| **Remote Logging Config** | Information about the Remote Logging Configuration file. |
| **Burst Logging Config** | Information about the Burst Logging Configuration file. |
| **Virtual Parameters** | Information about the Virtual Parameters file. |
| **CAN Config** | Information about the CAN Configuration file. |
| **External Inputs Config** | Information about the External Inputs Configuration file. |
| **Pot Board Config** | Information about the Pot Board Configuration file. |

**Notes:**

- All tabs display the filename and path of their files, and the Saved By and Saved On details. This information is read only. The Comment and Notes on all tabs can be edited if required.
- If a file is not loaded in the project, its tab is not displayed.
- The connection settings are on a separate [Connections tab](connections.md), opened with **File** > **Properties** > **Connections**.
