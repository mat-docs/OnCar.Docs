# Projects

A Project links all the files that are needed to work on an ECU. The files for a Project are stored in a Multi-Application Base. A Multi-Application Base can be associated with more than one Project, but each Project can only be associated with one Multi-Application Base. (When [Unit.Def](../unit-def-management/introduction.md) configuration is used, the files are stored in the project folder instead.)

A Project file (.prj) holds the locations of all the files used by the project. Use [Project Properties](properties/project-properties.md) to view the file locations. When you open a file, the Project changes to include the new file location. When you close the project, System Monitor offers to save the Project file if it has changed.

The ECU manufacturer may supply you with Project files. If not, you will have to [create a Project](creating-a-project/stage-1-define-project.md).
