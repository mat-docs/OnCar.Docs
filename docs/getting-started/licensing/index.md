# Licensing

System Monitor is licensed to a licence device in your PC, identified by its serial number. The supported licence devices are:

- a DESKey (DK2) dongle
- a network card (Ethernet adapter).

Licensing allows System Monitor activities (such as creating data sets or analysing logged data) to be carried out without an ECU connected.

Each licence is held in a licence file (`.lic`) on the local machine. The licence purchased from [Motion Applied](../../technical-support/motion-applied.md) allows System Monitor, up to a maximum version, to run with a particular dongle or network card. The licence file also defines:

- the Teams (or Consortiums) you can select as the Active Team - see [Team Security](../team-security-and-reduced-data-access/team-security.md)
- which Applications each Team has full, restricted or no access to - see [Reduced Data Access](../team-security-and-reduced-data-access/reduced-data-access.md)
- the options (features) that are enabled, such as ActiveX, Live Tune or Developer Functions
- an expiry date.

The software contains all features, but only the options in your licence are enabled. To add features, request an updated licence file from Motion Applied; you can do this from the Licence Manager with **Update**. See [Adding a Licence](adding-a-licence.md).

!!! note
    Licences are requested and generated online on the [Motion Applied portal](https://portal.motionapplied.com/).
