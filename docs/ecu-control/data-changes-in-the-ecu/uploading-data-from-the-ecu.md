# Uploading Data from the ECU

Select **ECU** > **Upload Data** (Alt+F7) to load the Data Version in the ECU into the System Monitor Edit Buffer (see [Developing Data Versions](../../project-management/developing-data-versions/index.md)). If the unit contains a different Program Version or Data Version, System Monitor opens the matching files first. You are prompted to save the contents of the Edit Buffer as a new Data Version file.

The command only acts on the Active Applications. The ECU is taken off-line during the upload and returned to its previous state afterwards.

**See also:** [Developing Data Versions](../../project-management/developing-data-versions/index.md); [ECU Control](../index.md)
