# ECU Control

System Monitor can program and control the ECU to which it is connected, using the commands on the ECU menu and the Tools menu.

The program is loaded into System Monitor as part of the process of [creating a Program Version](../project-management/program-and-data-versions/creating-a-program-version.md). The security features of the [Customer Base](../project-management/customer-bases/index.md) ensure that the program is suitable for the ECU.

## Features

- The [ECU Bar](../using-system-monitor/tool-and-information-bars/ecu-bar.md) shows the status of the ECU.
- [ECU On-Line](ecu-on-line.md) switches data acquisition from the ECU on and off.
- [Unit Status](unit-status.md) (**Tools** > **Unit Status**) shows the data versions and configuration files that are currently in System Monitor and in the main and spare units, and synchronises them.
- [ECU Search](ecu-search/index.md) gives details of the Program and Data Versions in the ECU.
- [ECU Memory](ecu-memory/index.md) commands reprogram the ECU and control whether it runs from RAM or ROM.
- [Kill Engine](kill-engine.md) (**Tools** > **Kill Engine**) stops the engine or prevents it from starting.
- [Setting Time and Date](setting-time-and-date.md) sets the ECU clock to match the PC.
- [Read Ram](ecu-memory/read-ram.md) (**Tools** > **Read RAM**) and [Single Message](single-message.md) (**Tools** > **Single Message...**) give low-level access to the ECU.
