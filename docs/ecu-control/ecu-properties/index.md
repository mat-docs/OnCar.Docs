# ECU Properties

When an ECU is connected, System Monitor can display information about it.

To open the ECU Properties dialog box, select **ECU** > **Properties**. The dialog box has the following tabs:

- [Controllers](ecu-properties-controllers.md) - View and enable/disable the controllers of each Application.
- [Devices](ecu-properties-devices.md) - Information about the ECU hardware.
