# Cursor Control and Trace

In a 1-axis or 2-axis Map, the active cell is selected by the values of the Breakpoints. The **Cursor Control** and **Trace** commands on the ECU menu use the active cell to help you with tuning. They are only available when there is communication with the ECU.

- **Cursor Control** - When checked, the edit cursor is positioned on the active cell, so that it is selected for editing.
- **Trace** - When checked, each cell that has been active since Trace was switched on is outlined in grey. Select **Show Trace as Block** in the map's Window System Menu to show the trace as filled cells.
