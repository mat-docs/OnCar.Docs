# Force Complete Reprogram

Force Complete Reprogram downloads all the program code, data and configurations to the ECU, whether they have changed or not. It is a diagnostic tool for embedded code developers. For normal updates, see [Reprogramming the ECU](reprogramming-the-ecu.md).

To start a complete reprogram, select **Tools** > **Force Complete Reprogram** (Alt+C). The Select Applications dialog box opens; operation is then the same as in [Reprogramming the ECU](reprogramming-the-ecu.md). The command is not available when **ECU read only mode** is set in Advanced Settings.

**ECU** > **Reprogram All** (Ctrl+Alt+P) performs a complete reprogram of all applications without the Select Applications dialog box, then downloads the Remote logging configuration.
