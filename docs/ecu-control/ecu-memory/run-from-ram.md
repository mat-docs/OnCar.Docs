# Run from RAM

Most types of ECU can operate from either RAM or ROM. By default, most ECUs run from RAM when connected to System Monitor.

Select **ECU** > **Run from RAM** to make the Active Applications run from RAM.

The command only acts on the Active Applications, and only if all of them can be locked for live tuning.

To switch Applications to ROM, see [Run from ROM](run-from-rom.md).

The [ECU Bar](../../using-system-monitor/tool-and-information-bars/ecu-bar.md) shows which memory each application is using.
