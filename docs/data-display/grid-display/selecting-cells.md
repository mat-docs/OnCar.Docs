# Selecting Cells

Click a single cell to select it, or use the cursor keys.

To select more than one cell using the mouse:

- Click and drag to select a continuous rectangle of cells. (If the text is highlighted, press ESC to select the cell.) Or
- Click on a corner of the rectangle of cells you want to select, then hold down the SHIFT key and click on the opposite corner. Or
- To select non-continuous cells, hold down the CTRL key while clicking on the cells. (Non-continuous blocks of cells cannot be copied.)

To select more than one cell using the keyboard:

- Using the cursor keys, select a cell at a corner of the rectangle of cells you want to select, then hold down the SHIFT key and select a cell at the opposite corner. Or
- To select non-continuous cells, hold down the CTRL key while using the cursor keys, and press the SPACE bar to accept cells. (Non-continuous blocks of cells cannot be copied.)

The commands in the Grid Cell Context Menu operate on all the selected cells, except **Properties**, which only operates on the first (top, left) of the selected cells. **Action Button** is only available when a single cell is selected.

**See also:** [Cell Properties](cell-properties.md)
