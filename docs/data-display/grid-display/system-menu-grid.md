# System Menu - Grid

The [System Menu](../../using-system-monitor/menus/window-system-menu.md) for a Grid Window contains the following options in addition to the standard commands:

| Item | Description |
|---|---|
| **Toggle Gridlines** | Shows or hides the gridlines. Default on. See [Cell Properties - Formatting](cell-properties-formatting.md). |
| **Toggle Edit Mode** | Switches [Edit Mode](grid-window-edit-mode.md) on and off. When on, the content and format of the cells can be modified. Default on for a new Grid Window. |
| **Import** | Replaces the Grid layout with one read from a Grid View XML file (`*.xml`). |
| **Export** | Saves the Grid layout to a Grid View XML file (`*.xml`). |

**See also:** [Grid](grid.md); [Window System Menu](../../using-system-monitor/menus/window-system-menu.md)
