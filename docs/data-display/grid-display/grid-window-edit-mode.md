# Grid Window Edit Mode

The Numeric Grid Display is normally used to show information about Parameters in a pre-arranged format. In day-to-day operation, the format of the grid should not need to be changed. To prevent accidental changes to the grid format, switch Edit Mode off by clearing the **Edit Mode** check box on the **Numeric Grid** tab of the Window Properties dialog box, or by selecting **Toggle Edit Mode** from the [System Menu](system-menu-grid.md).

Edit Mode is on, by default, for a new Grid Window.

When Edit Mode is on:

- The Column Header row is displayed and the column widths can be changed.
- The Grid Cell Context Menu is available.
- Text can be edited (see [Cell Properties - Contents](cell-properties-contents.md)).

When Edit Mode is off:

- The Column Header row is hidden.
- The values of Editable Parameters can be changed in their cells, and Slider and Button cells can be used.
- Right-clicking a cell that contains a Parameter opens the Parameter Properties dialog box for that Parameter, instead of the Grid Cell Context Menu.

**See also:** [Grid](grid.md); [System Menu - Grid](system-menu-grid.md)
