# Oscilloscope - Selecting Parameters

Parameters are selected in the [Parameter Info](oscilloscope-parameter-info.md) Box. To select a single parameter, click its Name or use the cursor keys.

To select more than one parameter using the mouse:

- Click on the first of the parameters you want to select, then hold down the SHIFT key and click on the last, or
- To select non-continuous parameters, hold down the CTRL key while clicking on the parameters.

To select more than one parameter using the keyboard:

- Using the cursor keys, select the first parameter, then hold down the SHIFT key and select the last parameter, or
- To select non-continuous parameters, hold down the CTRL key while using the cursor keys, and press the SPACE bar to accept parameters.

To select all the parameters, select **Select All** from the Context menu.
