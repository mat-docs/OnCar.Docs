# Event Priority

Events are defined by the Event file included in the [Program Version](../../../project-management/program-and-data-versions/index.md). The definition also sets a Priority level. The Priority level of each event is shown by a symbol in the **!** column of the Event Window:

- ![High](assets/Events_Red_Icon.gif) - **High**
- ![Medium](assets/Events_Blue_Icon.gif) - **Medium**
- ![Low](assets/Events_Green_Icon.gif) - **Low**

Events can also have **Debug** priority, which has its own symbol.

Events can be [Masked](event-mask.md) by their Priority level.

**See also:** [Event](index.md); [Event Mask](event-mask.md)
