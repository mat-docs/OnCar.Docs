# Event Log

Events are automatically logged to the file **Ev_*username*.txt** in the System Monitor log folder, where *username* is your log-in ID taken from the operating system. To open the log folder, select **Help** > **View Log Folder**.

If the Advanced Setting **Enable log file per project** (**Tools** > **Advanced Settings**) is on, the project name is added to the file name (**Ev_*username*_*project*.txt**).

Events can be saved to another file using the **Save Events As** command on the [ECU Menu](../../../using-system-monitor/menus/ecu-menu.md) or the **Save As** command on the [System Menu](system-menu-events.md) for the Event Window.

The files are in text format (`.txt`) and can be read by any text editor.
