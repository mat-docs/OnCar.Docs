# System Menu - Events

The System Menu for an Event Window contains the following items in addition to the standard commands:

| Item | Description |
|---|---|
| **Clear All Event Windows** | Clears all the events listed in all the Event Windows. Also available as **Clear Events** (F9) on the [ECU Menu](../../../using-system-monitor/menus/ecu-menu.md). |
| **Mask Unknown Events** | Hides Events that are not defined in the Event file. See [Event Mask](event-mask.md). |
| **Save As** | Saves the events to a text file. See [Event Log](event-log.md). |
| **Summary** | Switches Summary Mode on and off. In Summary Mode, only the most recent occurrence of each Event is listed. |
| **Normal Font** / **Large Font** | Selects the font size. |

**See also:** [Event](index.md); [Window System Menu](../../../using-system-monitor/menus/window-system-menu.md)
