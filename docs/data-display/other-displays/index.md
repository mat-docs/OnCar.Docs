# Other Displays

System Monitor can display information about an attached ECU that is neither a [Measurement Parameter](../../using-system-monitor/parameters/measurement-parameters.md) nor an [Editable Parameter](../../using-system-monitor/parameters/editable-parameters.md).

The following displays are available:

| Display | Description |
|---|---|
| [Error](errors/index.md) | Displays the error flags which are currently set on the ECU. |
| [Event](events/index.md) | Displays events received from the ECU. |
| [Read RAM](../../ecu-control/ecu-memory/read-ram.md) | A [Diagnostic](../../developer-functions/diagnostics.md) function. Displays the content of the memory for a particular controller in the attached ECU. |
| [Alarms](alarms/index.md) | Enables values of one or more Measurement Parameters to be used to trigger various actions. |

**See also:** [Developer Functions](../../developer-functions/index.md); [Editable Parameters](../../using-system-monitor/parameters/editable-parameters.md); [History Report](../../history-report/index.md); [Measurement Parameters](../../using-system-monitor/parameters/measurement-parameters.md)
