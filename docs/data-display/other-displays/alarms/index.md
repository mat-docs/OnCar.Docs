# Alarms

An Alarm consists of a Trigger and a set of Actions. The Actions are carried out as soon as the Trigger condition becomes TRUE.

**Trigger** - A Boolean (logical) statement that compares the value of one or more [Measurement Parameters](../../../using-system-monitor/parameters/measurement-parameters.md) with each other or with a constant.

**Actions** - Indications that a trigger event has occurred:

- Display a [Message](alarm-display.md)
- Jump to a Page
- Emit a sound

Alarms are created and managed in the [Alarms dialog box](alarm-setup.md) (**Desktop** > **Alarm Triggers**).
