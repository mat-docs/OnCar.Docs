# Alarm Properties

The **Alarm Properties** dialog box is opened from the [Alarms](alarm-setup.md) dialog box by clicking:

- **Add** - Opens an empty dialog box, or
- **Properties** - Opens the dialog box with the properties of the selected Alarm. The properties may be edited.

The dialog box consists of the following tabs:

- [Trigger](alarm-properties-trigger.md) - A Boolean (logical) statement that compares the values of one or more [Measurement Parameters](../../../using-system-monitor/parameters/measurement-parameters.md) with each other or with a constant.
- [Action](alarm-properties-action.md) - One or more indications that an event has occurred.

**See also:** [Alarms](index.md); [Alarm Setup](alarm-setup.md)
