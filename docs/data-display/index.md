# Data Display

System Monitor can display Measurement Parameters to give feedback during Tuning. While System Monitor is designed to display data, more detailed display and analysis can be achieved with the [ATLAS](../technical-support/atlas.md) data acquisition and analysis system. Contact [Motion Applied](../technical-support/motion-applied.md).

System Monitor displays the data from Measurement Parameters in Measurement Windows. Each display method uses a different Window. To add a Window to the current Page, select it from **Desktop** > **Window**. The following types are available:

| Window | Description |
|---|---|
| [Numeric](numeric-display/numeric.md) | Shows one or more Measurement Parameters. Each parameter is displayed in a row with descriptive text. |
| [Big Number](numeric-display/big-number.md) | A special version of the Numeric display using a large font. |
| [Bar Graph](bar-graph-display/bar-graph.md) | Shows one or more Measurement Parameters. Each parameter is displayed as a bar in which the height of the bar is proportional to the value of the parameter. |
| [Dial Gauge](dial-gauge-display.md) | Shows a Measurement Parameter on a dial. |
| [Oscilloscope](oscilloscope-display/oscilloscope.md) | Shows one or more Measurement Parameters. Each parameter is displayed as a plot against time. |
| [Grid](grid-display/grid.md) | A free-form display which allows you to place text and various attributes of any number of Measurement or Scalar Parameters in cells in a spreadsheet-style table. |
| [Signal Sampling](signal-sampling-display.md) | Samples (zeros) one or more input signal parameters. |
