# Bar Graph - Selecting Parameters

Select Parameters in the following ways:

- To select a single Parameter, click on its Bar or use the cursor keys.
- To select more than one Parameter using the mouse, hold down the CTRL key while clicking on the Parameters.
- To select more than one Parameter using the keyboard, hold down the CTRL key while using the cursor keys, and press the SPACE bar to accept Parameters.
- To select all the Parameters, select **Select All** from the Bar Graph Context Menu.

The Bar Graph Context Menu (right-click a bar) also has **Copy**, **Paste**, **Delete**, **Display Limits** and **Properties**.
