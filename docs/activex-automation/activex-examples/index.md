# ActiveX Examples

The following examples are written in [SM Script](../activex-client-languages/sm-script.md). The parameter identifiers they use are examples only; replace them with identifiers from your own program version.

- [ActiveX Example 1](activex-example-1.md): Using SendMessage() to send a Read RAM message to the ECU.
- [ActiveX Example 2](activex-example-2.md): Getting and setting the value of a scalar editable parameter.
- [ActiveX Example 3](activex-example-3.md): Getting values from a 1-axis map, axis, array and 2-axis map.
- [ActiveX Example 4](activex-example-4.md): Manipulating the values in a 1-axis map.
- [ActiveX Example 5](activex-example-5.md): Demonstrating functions GetValue2AxisMap and SetValue2AxisMap.
