# PCU Dash Properties

The PCU Dash Properties dialog box sets the properties that apply to the whole Dash Configuration.

To open the dialog box, do one of the following:

- Select **Dash Properties...** from the [Main Menu](../dash-configuration-main-menu.md) (icon at the left of the window's title bar), or press Alt+Enter.
- With no Control selected, right-click the display area and select **Dash Properties...**.

There are four tabs:

- [Display](display-tab.md)
- [Shift Lights](shift-lights-tab.md)
- [Actions](actions-tab.md)
- [Layout](layout-tab.md)
