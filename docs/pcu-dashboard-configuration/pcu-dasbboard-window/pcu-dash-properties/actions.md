# Actions

The following Actions can be selected in the [PCU Action](actions-tab.md#pcu-action-dialog-box) dialog box. Each Action is carried out when its Primary and (if set) Secondary conditions are met.

| Action | Description |
|---|---|
| **Page** | Goes to a specific page in the configuration. Enter the page in the **Number** box. |
| **LED** | Flashes an alarm LED. In the **Number** box enter 0 for the left-hand LED or 1 for the right-hand LED. |
| **Pg Up** | Goes to the next page in the configuration. |
| **Pg Down** | Goes to the previous page in the configuration. |
| **Backlight Dim** | Controls the brightness of the screen backlight. Enter a **Percentage** (0 to 100) of the backlight's full brightness. |
| **Shiftlight Dim** | Controls the brightness of the shift lights. Enter a **Percentage** (0 to 100) of the shift lights' full brightness. |
| **Flash All LEDs** | Flashes all LEDs (alarm LEDs and shift lights) for as long as the conditions are met. |

!!! note
    Pg Up and Pg Down can be used with the display unit push buttons, so that pressing a push button moves to the next or previous page. See [Assign Actions to push buttons](../../assign-actions-to-push-buttons.md).
