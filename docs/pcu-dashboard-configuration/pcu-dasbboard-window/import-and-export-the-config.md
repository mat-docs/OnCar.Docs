# Import and Export the config

Dash Configurations can be exported to a file, for example to pass to other users, and imported into the PCU Dash Configuration window to be viewed and edited. Single pages can be exported and imported in the same way.

| File type | Contents |
|---|---|
| .pcu | The whole Dash Configuration: all pages, shift lights and Actions. |
| .ppc | A single page. |

**To export a Dash Configuration:**

1. Select **Export Config...** from the [Main Menu](dash-configuration-main-menu.md).
2. In the Export PCU Config dialog box, browse to a location and enter a name for the .pcu file.

**To import a Dash Configuration:**

1. Select **Import Config...** from the Main Menu.
2. In the Import PCU Config dialog box, browse for an existing .pcu file.

The imported configuration replaces the one currently shown in the PCU Dash Configuration window.

**To export the current page:**

1. Select **Export Current Page...** from the Main Menu.
2. In the Export PCU Page Config dialog box, browse to a location and enter a name for the .ppc file.

**To import a page:**

1. Select **Import Page...** from the Main Menu.
2. In the Import PCU Page Config dialog box, browse for an existing .ppc file.

The imported page is added after the pages already in the configuration.
