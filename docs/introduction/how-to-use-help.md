# How to use Help

The System Monitor Help is an online documentation website. It opens in your default web browser when you:

- select **Help** > **Help Topics**, or press **F1**, in System Monitor
- click the **Help** button in a System Monitor dialog box that has one.

## Finding a topic

- **Navigation sidebar** - The tree on the left of each page lists every Help topic. It has the same sections, topic names and order as the Contents tab of the previous Help file. Click a section to expand it and click a topic to open it. The path to the current page is shown above the page title.
- **Search** - Type a word or phrase in the search box at the top of the page. Suggestions and matching topics are listed as you type; click a result to open it. The search terms are highlighted on the page. Press **F**, **S** or **/** to jump to the search box.
- **See also** - Most topics end with links to related topics.
- **Previous / Next** - Use the links at the bottom of each page to step through the topics in sidebar order.

## Moving around

- Use your browser's **Back** and **Forward** buttons to step through the topics you have viewed.
- On long pages, use the **Back to top** button that appears when you scroll up.
- To keep a topic, bookmark it in your browser, or print it using your browser's print command.

## Shortcut keys and procedures

- The System Monitor keyboard shortcuts are listed in [Keyboard Operation](../using-system-monitor/keyboard-operation.md).
- Procedures (step-by-step instructions) are shown as numbered lists within the relevant topic.
