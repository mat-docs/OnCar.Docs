# Puma Commands - Map Manipulation

The Map commands are available only in **Full-operation** mode. In Measurement mode they receive a *command not available* reply. They apply to 1-axis and 2-axis maps.

| System Monitor command | PUMA command | Function |
|---|---|---|
| Select Map | Select Lookup Table | Allows PUMA to nominate a map that it wishes to read or modify. PUMA sends: <br>- a LUN (must always be 1) <br>- the identifier of the map. <br>System Monitor assigns a number to the nominated map and returns: <br>- the map number, which PUMA uses to identify the map in the other Map Manipulation commands <br>- the number of breakpoints on the y and x axes. <br>PUMA may send more than one **Select Map** command. If the map has been selected before, the same number is returned. <br>If the parameter is not a map in the Project's system description, System Monitor replies with an *error during execution* [Error Message](puma-errors.md) ("Could not find the map"). |
| Get Map from System Monitor | Get Lookup Table from AP-S | Allows PUMA to request the complete contents of a map. PUMA sends: <br>- the map number. <br>System Monitor returns: <br>- the breakpoint values <br>- the minimum and maximum plausible physical limits for the map site values <br>- the minimum increment <br>- the map site values. |
| Put Map to System Monitor | Put Lookup Table to AP-S | Allows PUMA to send the complete contents of a map. PUMA sends: <br>- the map number <br>- the breakpoint values <br>- the minimum and maximum plausible physical limits and the minimum increment <br>- the map site values. <br>System Monitor sets the breakpoint and map site values as specified. The minimum increment and plausible physical limits sent by PUMA are ignored. <br>If any breakpoint or map site value is outside its limits, it is capped. System Monitor does not send an error message. <br>System Monitor replies with an *error during execution* [Error Message](puma-errors.md) if the size of the data does not match the map ("Lookup table length does not match the map size") or if an axis of the map cannot be edited ("Axis not editable"). |
| Get Map Value | Get Lookup Table Value | Allows PUMA to request the value of a single map site. PUMA sends: <br>- the map number <br>- the y and x index. <br>System Monitor returns: <br>- the specified map site value. |
| Set Map | Set Lookup Table | Allows PUMA to set the values of a map in a specific grid range. PUMA sends: <br>- the map number <br>- a start y and x index <br>- a y and x delta <br>- a single value. <br>System Monitor sets all map sites in the grid range to the specified value. <br>If the grid range includes a map site that is off the map, System Monitor replies with an *error during execution* [Error Message](puma-errors.md) ("Grid range outside of map"). <br>If the value is outside its limits, it is capped. System Monitor does not send an error message. |
| Increase Map | Increase Lookup Table | Allows PUMA to increase the values of a map in a specific grid range. PUMA sends: <br>- the map number <br>- a start y and x index <br>- a y and x delta <br>- a single offset value. <br>System Monitor increases all map sites in the grid range by the specified offset. <br>If the grid range includes a map site that is off the map, System Monitor replies with an *error during execution* [Error Message](puma-errors.md) ("Grid range outside of map"). <br>If any of the new values is outside its limits, it is capped. System Monitor does not send an error message. |

If PUMA uses a map number that has not been assigned by **Select Map**, System Monitor replies with *error during execution* ("Invalid map"). Changes made by PUMA are made in the Edit Buffer and, if Live Tune is on, downloaded to the ECU.
