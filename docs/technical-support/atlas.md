# ATLAS

ATLAS is Motion Applied's software for the display and analysis of motorsport data. It displays live telemetry data as it arrives and analyses logged data uploaded from the vehicle after a run.

ATLAS can be used alongside System Monitor. For example, System Monitor can connect to a unit through an ATLAS data server (see [Connections](../project-management/projects/properties/connections.md)), and ATLAS and System Monitor share the same Licence Manager and licence files.

For more information, see the [ATLAS documentation](https://atlas.motionapplied.com/) or contact [Motion Applied](motion-applied.md).
