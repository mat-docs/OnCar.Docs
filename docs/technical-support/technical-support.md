# Technical Support

Before contacting Technical Support, please check this Help. If you still cannot solve the problem, contact Motion Applied support:

- **Support portal:** [portal.motionapplied.com](https://portal.motionapplied.com/) - raise a support ticket, and download software and licences
- **Web site:** [motionapplied.com](https://motionapplied.com/)
- **Telephone:** +44 (0)1483 966 800

If you believe that there is a fault with the system, please tell us how to reproduce the problem and send copies of any relevant files, including the [System Log](../developer-functions/system-log.md) files. To find the log files, select **Help** > **View Log Folder** in System Monitor. Please also tell us the System Monitor version, shown in **Help** > **About System Monitor**.

**See also:** [Motion Applied](motion-applied.md); [ATLAS](atlas.md)
