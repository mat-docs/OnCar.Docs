# Desktop

The Desktop is the System Monitor working environment.

![Desktop example](assets/Main_Window_Project.gif)

A Desktop consists of one or more Pages that contain Windows. Every Project has a Desktop associated with it. Any Project can use any Desktop in the Multi-Application Base but can only have one Desktop loaded at any one time.

There is no restriction on the layout, size and number of Windows on a Page or on the number of Pages in a Desktop.

Desktops can be used for specific purposes. For example, a Desktop can be set up for a particular task or function, such as testbed dyno operation, trackside support, or powertrain and engine optimisation. Typically, Pages are used for specific aspects of the vehicle operation, for example engine status, chassis sensors or ignition mapping.

A full Desktop, complete with a number of Pages containing appropriate Windows, may be provided by the embedded control system engineers. This can be used as it is, modified, or used as the basis for your own Desktop.

The commands for working with the Desktop are on the [Desktop Menu](../menus/desktop-menu.md).
