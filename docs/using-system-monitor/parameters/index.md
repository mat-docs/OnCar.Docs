# Parameters

Any item of data processed by the ECU is called a Parameter. All operations in System Monitor act on, or use, Parameters.

There are two types of Parameter:

- **[Editable Parameters](editable-parameters.md)** – the information used by the embedded control system in the ECU to control its performance. Also known as Configurable or Tune data. Examples are fuel injection quantity look-up tables, engine idle speeds and ignition maps. Tuning is the process of optimising the values of Editable Parameters.
- **[Measurement Parameters](measurement-parameters.md)** – the information gathered by the ECU from sensors or generated by its own operation. Also known as On-Line information. Examples are engine speed and water temperature. Logging, or Data Acquisition, is the process of obtaining this information. System Monitor includes tools to control Logging, and can display the values of Measurement Parameters.

Each Parameter has [Properties](parameter-properties/index.md). Most of these are defined in the ASAP file by the ECU manufacturer and can be viewed, but not edited, in System Monitor. The remaining properties can be edited.
