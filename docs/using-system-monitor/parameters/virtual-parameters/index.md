# Virtual Parameters

A Virtual Parameter is a Measurement Parameter whose value is the result of applying mathematical operations to one or more existing Measurement Parameters.

For example, a differential pressure parameter may be created from the difference between two absolute pressure values.

Virtual Parameters are listed in the **Virtual Parameters** group in Parameter Explorer and are stored in the project's [Virtual Parameter file](virtual-parameter-files.md). The type name of a Virtual Parameter is *Virtual Measurement*.
