# Selecting parameters to Edit or Display

Parameters must be loaded into a Window before they can be viewed and edited. Single or multiple Parameters can be loaded, depending on the type of Window.

## Loading multiple Parameters

The following Windows accept multiple Parameters:

- [Numeric](../../../data-display/numeric-display/numeric.md)
- [Scalar](../../../tuning/scalar-window.md)
- [1-axis Map](../../../tuning/1-axis-map-window/1-axis-map.md) (provided that each parameter uses the same axis)
- [String](../../../tuning/string-window.md)

To load multiple Parameters, see [Multiple Parameter Selection](multiple-parameter-selection-window-properties.md).

## Loading a single Parameter

The following Windows accept a single Parameter:

- [Grid](../../../data-display/grid-display/grid.md) (in a cell)
- [2-axis Map](../../../tuning/2-axis-map-window.md)
- [Array](../../../tuning/array-window.md)

To load a single Parameter, see [Single Parameter Selection](single-parameter-selection-window-properties.md).

Selected Parameters can be cut, copied and pasted from other Windows or from Parameter Explorer using the **Edit** menu commands or their shortcuts.

You can also drag selected Parameters or Groups from Parameter Explorer and drop them into a compatible Window.
