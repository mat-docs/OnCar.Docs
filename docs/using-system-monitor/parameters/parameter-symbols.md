# Parameter Symbols

Each Parameter type is identified by an icon:

| Symbol | Parameter type |
|---|---|
| ![Measurement](assets/Measurement_Icon.gif) | [Measurement Parameter](measurement-parameters.md) |
| ![Scalar](assets/Scalar_Icon.gif) | [Scalar Editable Parameter](../../tuning/scalar-window.md) |
| ![1-axis map](assets/1-axis_Icon.gif) | [1-axis Map Editable Parameter](../../tuning/1-axis-map-window/1-axis-map.md) |
| ![2-axis map](assets/2-axis_Icon.gif) | [2-axis Map Editable Parameter](../../tuning/2-axis-map-window.md) |
| ![Array](assets/Array_Icon.gif) | [Array Editable Parameter](../../tuning/array-window.md) |
| ![String](assets/String_Icon.gif) | [String Editable Parameter](../../tuning/string-window.md) |
| ![Live Auto Tune](assets/Live_Auto_Icon.gif) | [Live Auto Tune](../../tuning/live-auto-tune.md) |
| ![Virtual](assets/Virtual_Icon.gif) | [Virtual Parameter](virtual-parameters/index.md) |
| ![Locked](assets/icon_locked_measparam.gif) | [Locked Parameter](locked-parameters/locked-parameters.md) – the Parameter icon is overlaid with a lock (a Measurement Parameter is shown). The Parameter is locked and cannot be edited or added to the Desktop. |

These symbols are displayed in:

- Parameter Explorer
- the Select Parameter(s) dialog boxes
- the Data Wizard Report View and Candidate View
