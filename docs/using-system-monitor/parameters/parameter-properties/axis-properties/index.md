# Axis Properties

The axes used by 1-axis and 2-axis Map Parameters have a set of properties defined by the ECU manufacturer in the ASAP file. Many are read only in the Axis Properties dialog box.

To open the Axis Properties dialog box, click **Properties** next to the axis **Identifier** on the [1-Axis Map](../1-axis-map-tab.md) or [2-Axis Map](../2-axis-map-tab.md) tab of the Parameter Properties dialog box.

The dialog box has three tabs:

- [General](axis-properties-general.md) – displays information about the axis.
- [Editable](../editable-tab.md) – displays the Editable Parameter properties of the axis, defined by the ECU manufacturer in the [ASAP](../../../../project-management/asap-compatibility.md) file.
- [Conversion](axis-properties-conversion.md) – displays information about the conversion used for the axis, and allows you to edit the limits and format.

**See also:** [1-axis Map](../../../../tuning/1-axis-map-window/1-axis-map.md); [2-axis Map](../../../../tuning/2-axis-map-window.md)
