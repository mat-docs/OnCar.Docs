# Printer Support

The options for printing the contents of Windows are:

- **To print the selected Window only** - Select **File** > **Print...** (CTRL+P) or click ![Print](assets/Print_Icon.gif) on the [Standard Tool Bar](../tool-and-information-bars/standard-tool-bar.md).
- **To print all the Windows on the current Page** - Select **Desktop** > **Page** > **Print**. Data Wizard Windows, and Windows that originate on a different Page but are set to Appear on every Page, are not printed.
- **To print Data Wizard Windows** - See [Printing Data Wizard Windows](printing-data-wizard-windows.md).

The format of the printout depends on the type of Window:

| Window | Printout |
|---|---|
| Windows containing Editable Parameters | Text showing the current value of each Parameter. Maps are shown in a text grid format. |
| Numeric | Text showing the current value of each Parameter. |
| Grid | Text image of the Window. |
| Bar Graph and Oscilloscope | Bitmap image of the Window. |

Select **File** > **Print Preview...** to view the printout before sending it to a printer. See [Print Preview](print-preview.md).

Use **File** > **Print Setup...** to select the printer and printing options, and **File** > **Page Setup...** to set up the page.

!!! note
    You can also print the Engine details of a [History Report](../../history-report/index.md) and the contents of a [Sensors & Actuators dialog box](../../data-acquisition/sensors/sensors-and-actuators/sensors-and-actuators-dialog-box.md).

**See also:** [File Menu](../menus/file-menu.md); [Pages](../pages/index.md)
