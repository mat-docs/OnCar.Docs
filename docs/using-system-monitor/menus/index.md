# Menus

The Menu Bar changes when a Project is opened or closed.

When no Project is open, the Menu Bar contains the **File**, **Edit**, **View**, **Tools**, **Desktop** and **Help** menus. These contain a reduced set of commands (for example, the Desktop menu contains only **Close All**, which is unavailable).

When a Project is open, the following menus are available:

| Menu | Use it to | Shortcut |
|---|---|---|
| [File Menu](file-menu.md) | Work on [Project files](../../project-management/files/types-of-files/project-files.md) and Applications. Includes [Printing](../printing/printer-support.md). | ALT+F |
| [Edit Menu](edit-menu.md) | Work on [Parameters](../parameters/index.md) and their values. Includes [Parameter Explorer](../parameters/parameter-explorer.md) commands. | ALT+E |
| [View Menu](view-menu.md) | Control the Parameter Explorer and the [Tool and Information Bars](../tool-and-information-bars/index.md). | ALT+V |
| [ECU Menu](ecu-menu.md) | Work with [ECUs](../../ecu-control/index.md). | ALT+U |
| [Sensors Menu](sensors-menu.md) | Work with [Sensors](../../data-acquisition/sensors/index.md), sensor sets and External Inputs. | ALT+N |
| [Logging Menu](logging-menu.md) | Work with [Logging](../../data-acquisition/logging/index.md) configurations. | ALT+L |
| [Tools Menu](tools-menu.md) | Access additional tools within System Monitor. | ALT+T |
| [Data Wizard Menu](data-wizard-menu.md) | Work with [Data Wizard](../../project-management/data-wizard/index.md). The menu is labelled **DataWizard**. | ALT+W |
| [Desktop Menu](desktop-menu.md) | Create and edit Pages and Windows. | ALT+D |
| [Help Menu](help-menu.md) | Open the Help, log folders and Configuration API documentation, and manage [Licences](../../getting-started/licensing/adding-a-licence.md). | ALT+H |

!!! note
    The **Sensors** menu is not shown if an Application in the Project indicates (in its system constants) that it does not support sensor calibration. The **Desktop** menu is unavailable with a Formula E licence.

To use the Menu Bar with the keyboard, press ALT, then either:

- use the cursor keys to select a command and press ENTER to run it, or
- press the key for the underlined character in each menu or sub-menu.

Press ALT or ESC to close the menu without running a command.

Many commands also have shortcut keys, which are shown against the command in the menu. See [Keyboard Operation](../keyboard-operation.md).
