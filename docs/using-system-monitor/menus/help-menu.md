# Help Menu

| Command | Description |
|---|---|
| **Help Topics** | Opens the System Monitor Help. |
| **Decode Message Log...** | Decodes a System Monitor IP message log (`SM_Msgs_*.txt`) from the log folder. Only on the menu when a Project is open. |
| **View Log Folder** | Opens today's log folder (`SysMonLogs_yyyy.mm.dd`) in the location set by the Advanced Setting **Directory for log files**. See [System Log](../../developer-functions/system-log.md). |
| **Configuration API Documentation** | Opens the [Configuration API](../../configuration-api/index.md) documentation in your web browser. |
| **Licence Manager...** | Opens the [Licence Manager](../../getting-started/licensing/adding-a-licence.md), where you add new or remove existing System Monitor Licences. |
| **About System Monitor...** | Displays System Monitor information, version number and copyright. |

**See also:** [Menus](index.md); [Settings](../settings.md)
