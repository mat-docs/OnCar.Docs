# Context Menus

To open a Context menu, right-click in the required area or press SHIFT+F10. Alternatively, use the keyboard context menu key ![Context menu key](assets/context_icon_small.gif) if available.

The commands on a Context menu depend on the location of the mouse pointer and on the item selected.

The following Context menus are available:

| Context menu | Use it to |
|---|---|
| [Edit Context Menu](edit-context-menu.md) | Edit text or numbers in a [Parameter Filter](../../parameters/selecting-parameters/parameter-filter.md), in the **Value** of an Editable Parameter or in any editable text box. |
| [Windows Context Menu](windows-context-menu.md) | Carry out operations on a Parameter in a Window. |
| [Data Wizard Context Menu](data-wizard-context-menu.md) | Work with Parameters in [Data Wizard](../../../project-management/data-wizard/index.md). |
| [Select Parameter Context Menu](select-parameter-context-menu.md) | Change the appearance of the Select Parameter(s) dialog boxes for [Multiple](../../parameters/selecting-parameters/selecting-multiple-parameters.md) or [Single](../../parameters/selecting-parameters/selecting-a-single-parameter.md) Parameters. |
| [Parameter Explorer Context Menu](parameter-explorer-context-menu.md) | Change the appearance of Parameter Explorer and work with Applications, Groups and Parameters. |
| [Oscilloscope Context Menu](oscilloscope-context-menu.md) | Work with the Parameters in an [Oscilloscope Window](../../../data-display/oscilloscope-display/oscilloscope.md). |
| [Bar Graph Context Menu](bar-graph-context-menu.md) | Work with the Parameters in a [Bar Graph Window](../../../data-display/bar-graph-display/bar-graph.md). |
| [Grid Cell Context Menu](grid-cell-context-menu.md) | Carry out operations on a **Cell** in a [Grid](../../../data-display/grid-display/grid.md) Window. |
| [Tool Bar Context Menu](tool-bar-context-menu.md) | Control the appearance of floating [Tool and Information Bars](../../tool-and-information-bars/index.md). |

Commands that affect the Window as a whole (for example display format, fonts and Lock Window) are on the [Window System Menu](../window-system-menu.md).
