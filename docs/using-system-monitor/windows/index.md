# Windows

Windows are used to display Parameters. Any number of Windows can be added to a Page. Window arrangements and definitions are stored in the Desktop.

There are two types of Window for displaying Parameters:

- [Edit Windows](edit-windows.md) - display Editable Parameters.
- [Measurement Windows](measurement-windows.md) - display Measurement Parameters.

Windows are also used to display the following specialised information:

- [Errors](../../data-display/other-displays/errors/index.md) - ECU reported errors.
- [Events](../../data-display/other-displays/events/index.md) - time-stamped events.
- [Alarms](../../data-display/other-displays/alarms/index.md) - alarms set up with Alarm Triggers.
- [Read RAM](../../ecu-control/ecu-memory/read-ram.md) - ECU diagnostic information.
- [Signal Sampling](../../data-display/signal-sampling-display.md) - sampling of input signals.
- [Dashboard](../../pcu-dashboard-configuration/pcu-400-display-unit.md) - configuration of a PCU-400 display unit.
- Pot Board - parameters adjusted with the [Adjustment Board](../../tuning/adjustment-board-control/adjustment-board-control.md).

## Data Wizard

Data Wizard uses special, temporary Windows that are not retained as part of the Desktop.
