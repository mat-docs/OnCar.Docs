# Window Properties

To open the **Window Properties** dialog box, do one of the following:

- Select **Window Properties...** on the [Window System Menu](../../menus/window-system-menu.md).
- Select **View** > **Properties**.
- Select **Desktop** > **Window** > **Properties**.
- Press ALT+ENTER.

The dialog box has the following tabs:

- **Display** - Controls the appearance of the Window. See [Window Properties – Display tab](window-properties-display-tab.md).
- **Parameters** (or **Parameter** for Windows that hold a single Parameter) - Configures the Parameters in the Window. See [Selecting parameters to Edit or Display](../../parameters/selecting-parameters/selecting-parameters-to-edit-or-display.md).
