# Using Windows

A newly [Created Window](../creating-windows/index.md) appears on the current [Page](../../pages/index.md). Windows can be selected, moved and resized within the Page.

Click anywhere on a Window to select it, or use CTRL+TAB to cycle through the Windows on the Page.

The columns in some Windows can be resized. See [Columns in Tabular Windows](columns-in-tabular-windows.md).

Select **Desktop** > **Window** to access the commands for managing Windows:

| Command | Description |
|---|---|
| **Close** (CTRL+F4) | Closes the current Window. |
| **Show Column Headings** | Shows or hides the column headings in the Window in focus. |
| **Lock Window** | Locks the size and position of the Window in focus and disables its System Menu. |
| **Properties** | Opens the [Window Properties](window-properties.md) dialog box for the Window in focus. ALT+ENTER also opens it. |
| **Cascade** | Makes all the Windows the same size and overlaps them with their title bars showing. The original layout is lost. |
| **Tile** | Lays out all the Windows on the Page, sizing them to fit without overlapping. The original layout is lost. |

Further commands for each Window are on its [Window System Menu](../../menus/window-system-menu.md).
