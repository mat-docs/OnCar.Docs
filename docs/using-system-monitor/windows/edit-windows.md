# Edit Windows

Each type of Editable Parameter has a specific type of Window. The following types of Editable Parameter are supported:

- [Scalar](../../tuning/scalar-window.md)
- [1-axis map](../../tuning/1-axis-map-window/1-axis-map.md)
- [2-axis map](../../tuning/2-axis-map-window.md)
- [Array](../../tuning/array-window.md)
- [String](../../tuning/string-window.md)

Editable Parameters can be edited and viewed in a number of formats, including engineering units, raw hexadecimal, raw decimal and (for 1-axis and 2-axis maps) graphically as a line or wire mesh view. See [Window System Menu](../menus/window-system-menu.md).

More than one Window can contain the same Editable Parameter to give multiple views. For example, you can view a graphical representation of a 2-axis map in one Window while editing the values in another.

Scalar parameters can also be included in a [Grid](../../data-display/grid-display/grid.md) window. Pot Board windows show the parameters assigned to the [Adjustment Board](../../tuning/adjustment-board-control/adjustment-board-control.md).
