# Measurement Windows

The data from Measurement Parameters can be displayed in the following types of Window:

- [Numeric](../../data-display/numeric-display/numeric.md)
- [Bar Graph](../../data-display/bar-graph-display/bar-graph.md)
- [Oscilloscope](../../data-display/oscilloscope-display/oscilloscope.md)
- [Grid](../../data-display/grid-display/grid.md)
- [Dial Gauge](../../data-display/dial-gauge-display.md)
- [Signal Sampling](../../data-display/signal-sampling-display.md)

Each display method uses a different Window. More than one Window can contain the same Measurement Parameter to give multiple views. For example, you can view an Oscilloscope trace in one Window while showing the same parameter as a Dial Gauge in another.

A Grid window can also include Scalar parameters.

!!! note
    **Big Number** is listed on the **Desktop** > **Window** sub-menu but is always unavailable. See [Big Number](../../data-display/numeric-display/big-number.md).

**See also:** [Measurement Parameters](../parameters/measurement-parameters.md); [Data Display](../../data-display/index.md)
