# Creating Windows

Windows can be created in two ways:

- Create an [Empty Window](creating-empty-windows.md) using the **Desktop** > **Window** sub-menu, and load one or more Parameters into it.
- Create Windows containing Parameters from Parameter Explorer. See [Creating Windows with Parameter Explorer](creating-windows-with-parameter-explorer.md).

## Features

- New Windows are placed on the current Page of the Desktop. Windows cannot be added to a locked Page.
- Most Windows display one or more Parameters. The exceptions are the [Error](../../../data-display/other-displays/errors/index.md), [Event](../../../data-display/other-displays/events/index.md), [Alarm](../../../data-display/other-displays/alarms/index.md) and [Read RAM](../../../ecu-control/ecu-memory/read-ram.md) windows.
- You can only create Windows for the Parameter types available in the Project. If a type of Parameter is not present, the command to create a Window for that type is unavailable.
- Windows can be copied or moved (for example, to another Page) using the **Cut**, **Copy** and **Paste** commands on the [Edit Menu](../../menus/edit-menu.md) or their shortcuts.
