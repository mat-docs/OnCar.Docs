# Changing Parameter Values

Each parameter is defined in the ASAP file by the ECU manufacturer. The ASAP file either permits or prevents System Monitor from changing the values of an Editable Parameter. If the values cannot be changed, the edit boxes are disabled.

You can only change values of parameters in an Application that is Active and not Read Only.

**To change an Editable Parameter value:** select the value and enter a new one. See [Changing Parameter Values by Mouse](changing-parameter-values-by-mouse.md) and [Changing Parameter Values by Keyboard](changing-parameter-values-by-keyboard.md).

!!! note
    Parameter values can also be changed in Graphical Maps (see [Changing Values in a Graphical view](../graphical-maps/changing-values-in-a-graphical-view.md)).

When a value is changed and accepted, its colour changes to the Greater than / Less than colour (default red/blue) as appropriate. These colours are set in the Display tab of the Window Properties dialog box. The [Scalar](../scalar-window.md) window also uses arrow icons to show the direction of value changes.

## Editing options

- Edit commands are available on the [Edit Context Menu](../../using-system-monitor/menus/context-menus/edit-context-menu.md).
- Use the [Maths Bar](../../using-system-monitor/tool-and-information-bars/maths-bar.md) to carry out mathematical operations on the selected value or values.
- The Breakpoint values of 1-Axis and 2-Axis Maps can be edited. See [Changing Breakpoint Values](changing-breakpoint-values-by-mouse.md).
- To restore values to the values saved on disk, select **Edit** > **Restore Value** (F2), or **Restore Value** on the context menu.
