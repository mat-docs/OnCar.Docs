# Changing Parameter Values by Mouse

Click the value to be changed and enter a new number to overwrite the existing value. Alternatively, click the appropriate edit box in the Edit Bar and enter a new value.

![2-axis map Edit Bar](assets/EditValue_Breakpoint.gif)

2-axis map Edit Bar

**To select more than one value, do one of the following:**

- Click and drag to select a rectangle of values. (If the value is in Edit Mode, press ESC before dragging.)
- Click a cell at one corner of the rectangle of values you want to select, hold down the SHIFT key and click the cell at the opposite corner.
- To select non-contiguous values, hold down the CTRL key while clicking values. (Non-contiguous blocks of values cannot be copied.)

If multiple values are selected, entering a value overwrites the first (top left) of the selected values. The Maths Bar operates on all the selected values.

!!! note
    You can also change values by dragging with the mouse in a Graphical Map (see [Changing Values in a Graphical view](../graphical-maps/changing-values-in-a-graphical-view.md)).
