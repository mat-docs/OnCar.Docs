# Changing Parameter Values by Keyboard

Select the value to be changed using the cursor keys and enter a new number to overwrite the existing value. Alternatively, use the TAB key to cycle through the edit boxes in the Edit Bar.

![2-axis map Edit Bar](assets/EditValue_Breakpoint.gif)

2-axis map Edit Bar

**To select more than one value:**

- Using the cursor keys, select a cell at one corner of the rectangle of values you want to select. Hold down the SHIFT key and select the cell at the opposite corner.
- To select non-contiguous values, hold down the CTRL key while using the cursor keys and press the SPACE bar to include values. (Non-contiguous blocks of values cannot be copied.)

If multiple values are selected, entering a new value overwrites the first (top left) of the selected values. The Maths Bar operates on all the selected values.
