# Graphical Maps

1 axis and 2 axis Maps can be displayed in various graphical formats.

Select the view format from the [Window System Menu](../../using-system-monitor/menus/window-system-menu.md) or step through the options with the **View mode** button on the [Map Bar](../../using-system-monitor/tool-and-information-bars/map-bar.md). **Toggle Grid / Graphical** (Alt+G) switches between the last grid view and the last graphical view.

The following views are available for a 1-axis Map:

- [Graphical View – 1 axis](graphical-view-1-axis.md) (**Graphical**) - a two-dimensional graph of parameter value plotted against Index Value.
- [Difference View](difference-view.md) (**Difference**) - a two-dimensional graph of the difference between the value of the parameter in the Edit Buffer and its value in the Data Version, plotted against Index Value.

The following views are available for a 2-axis Map:

- [Graphical View – 2 axis](graphical-view-2-axis.md) (**Graphical**) - a three-dimensional graph of parameter value plotted against two Index Values.
- [Difference View](difference-view.md) (**Difference**) - a three-dimensional graph of the difference between the value of the parameter in the Edit Buffer and its value in the Data Version, plotted against two Index Values.
- [End View](end-view.md) (**End**) - a two-dimensional graph, for each Y Index Value, of parameter value plotted against X Index Value.
- [Slice View](slice-view.md) (**Slice X** / **Slice Y** buttons on the Map Bar) - a two-dimensional graph along the X or Y axis through the selected value.

All graphical views can be [zoomed](zooming-a-graphical-view.md), and graphical views of 2 axis Maps can be [rotated](rotating-a-graphical-view.md). The [Breakpoint Spacing](breakpoint-spacing.md) can be constant or proportional.

You can [change values](changing-values-in-a-graphical-view.md) in graphical views.
