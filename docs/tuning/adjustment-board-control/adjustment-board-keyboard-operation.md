# Adjustment Board Keyboard Operation

The keyboard can be used to duplicate the Adjustment Board controls, whether or not the board is connected.

| Keys | Action |
|---|---|
| Ctrl+1 to Ctrl+4 | Increase: equivalent to turning control 1 to 4 (switch position 1) one click to the right. |
| Ctrl+Shift+1 to Ctrl+Shift+4 | Decrease: equivalent to turning control 1 to 4 (switch position 1) one click to the left. |
| Ctrl+5 to Ctrl+8 | Increase: controls 1 to 4 in switch position 2. |
| Ctrl+Shift+5 to Ctrl+Shift+8 | Decrease: controls 1 to 4 in switch position 2. |

!!! note
    Use the number keys on the main part of the keyboard, not those on the number pad.

As with the board itself, the value only changes while the ECU is On-Line. The size of each step is the **Step** set for the row in the [Pot Board Configuration](adjustment-board-configuration.md) window.

**See also:** [Adjustment Board Control](adjustment-board-control.md)
