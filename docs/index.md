# Introduction

System Monitor is an integrated software application that gives access to the features of Electronic Control Units (ECUs) and associated systems.

Whenever these systems are used, whether for trackside support, unit optimisation, dyno testing, or during development and production, System Monitor provides tools for ECU program management, tuning and configuration.

System Monitor is optimised for Motion Applied (TAG) control systems. It can also be used with third-party controllers, but some hardware modification may be required.

The functions of System Monitor fall into the following categories:

- **ECU program management** - Manage ECU program files so that the latest versions can be uploaded and downloaded. See [Project Management](project-management/index.md) and [ECU Control](ecu-control/index.md).
- **Tuning** - View and modify [Editable Parameters](using-system-monitor/parameters/editable-parameters.md) to change the way the ECU operates. Changes can be sent to the ECU immediately ([Live Tune](tuning/live-tune.md)) or made with the ECU offline. System Monitor can be used with a [Testbed](testbed-operation/index.md) for automatic tuning. See [Tuning](tuning/index.md).
- **Displaying parameter information** - Display [Measurement Parameters](using-system-monitor/parameters/measurement-parameters.md) to give live feedback during tuning. See [Data Display](data-display/index.md).
- **Configuring data logging** - Configure the data logging capabilities of TAG ECUs. See [Logging](data-acquisition/logging/index.md).
- **Configuring sensors** - Calibrate the sensors and actuators connected to an ECU, and configure the DATA*Lab* system. See [Sensors](data-acquisition/sensors/index.md).
- **Automation** - Control System Monitor from other applications through [ActiveX Automation](activex-automation/index.md) or the gRPC-based [Configuration API](configuration-api/index.md).
