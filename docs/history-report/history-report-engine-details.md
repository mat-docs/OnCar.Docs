# History Report - Engine Details

To open the Engine Details dialog box for an engine data set, select its row in the Engine panel of the [History Report – Summary](history-report-summary.md) tab and press ENTER, or double-click it.

The dialog box has the following tabs:

- [Time](engine-details-time.md) - Shows a breakdown of the amount of time that the selected engine was in selected combinations of engine speed and throttle opening.
- [Cycles](engine-details-cycles.md) - Shows a breakdown of the number of cycles during which the selected engine was in selected combinations of engine speed and throttle opening.
- [Auxiliary Engine Details](engine-details-auxiliary.md) - Shows diagnostic data for the selected engine.

The breakpoints and condition values used in the Engine Details dialog box can be modified in the [Setup](history-report-setup.md) tab of the History Report dialog box.

Click **Print** to print a text version of the information on the selected tab.
