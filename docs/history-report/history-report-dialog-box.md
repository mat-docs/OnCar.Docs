# History Report dialog box

The History Report dialog box is opened when:

- An existing [History Report file](history-report-files.md) is opened using **File** > **Open**, or with **Tools** > **History Report** > **Open *filename***
- **Tools** > **History Report** > **Upload** is selected
- A new History Report file is created using **File** > **New**

The History Report file name is shown in the title bar. The dialog box has two tabs:

- [Summary](history-report-summary.md) - Shows totals of statistics for all the Chassis and all the Engines for which history data has been obtained and gives access to detailed reports.
- [Setup](history-report-setup.md) - Allows the way history data is collected to be modified.
