# PC System Requirements

| Component | Minimum | Recommended |
|---|---|---|
| **Processor** | Intel Core Duo 2 GHz | Intel Core i7 |
| **Memory** | 1 GB | 8 GB or more |
| **Disk space** | HDD with 200 GB free disk space | High-capacity SSD, 512 GB or more |

| Item | Requirement |
|---|---|
| **Operating system** | 64-bit Windows 10. The installer installs the 64-bit Microsoft .NET 8 Desktop Runtime and ASP.NET Core Runtime, which System Monitor needs. |
| **Installation** | Download the installer from the [Motion Applied portal](https://portal.motionapplied.com/). |
| **Licence device** | A DESKey (DK2) dongle, or a network card. See [Licensing](../getting-started/licensing/index.md). |
| **Power supply** | We strongly recommend that a laptop PC can recharge its battery rapidly (not trickle charge) while applications are running. |

**See also:** [Installation](../getting-started/installation.md)
