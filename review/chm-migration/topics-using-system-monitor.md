# CHM migration check — Batch A ("Using System Monitor", 99 topics)

Docs root: `C:\MclDev\SystemMonitor.Site\docs\` (paths below are relative to `docs/user-guide/` unless shown otherwise).

Overall: the `using-sm/` section (index.md, menus.md, windows-parameters.md, advanced.md) is a thin, generic rewrite. Menus are mostly just screenshots; Tool/Information bars, Window System menu, context menus, Parameter Explorer, parameter selection dialogs, all Parameter Properties tabs, Axis/Conversion dialogs, Virtual Parameter authoring, and Printing are largely absent. Some generic text in `advanced.md` does not match the CHM (e.g. "Axis Properties: Linear or logarithmic scaling", "Mathematical Operators: AND/OR/NOT", "Number Formats" lists display modes rather than the format-string syntax, and "Shortcuts can be customised in the settings menu"). Treat those sections as needing a rewrite, not as coverage.

Source check (read-only, `C:\MclDev\ATLAS9\ATLASSM\Main\SMv7\SMv7\SysMonApp.rc`): Desktop > Window still lists Pot Board, Big Number, Dial Gauge, Event, Signal Sampling, Dashboard and "Grid from Import...". Desktop > Page still lists Zero All Measurements, Clear All Display Offsets On Page, "Resize Views On Page To Fit Contents" (new, not in CHM), Lock Page, Close Unlocked Windows, Restore Layout, Print and Print Preview. Show Application Pages and Close All are also there, and Help includes Decode Message Log, View Log Folder and Configuration API Documentation. The "View Documentation" context items and the Modem and Log-IP-Transactions toolbar buttons still exist in the resources. None of the missing topics looked obsolete.
