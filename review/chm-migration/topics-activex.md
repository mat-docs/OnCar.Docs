## Method-name reconciliation (CHM vs methods.md)
- CHM methods absent from the site (17, all confirmed in SystemMonitor.odl): GetStringValueScalar, RemoveAllVirtualParametersFromGroup, RemoveVirtualParameterGroup, SetVirtualParameterToGroup, SetVirtualParameterToGroupWithDataType, GetRationalConvFromApp, GetTableConv, GetTableConvFromApp, GetTextConv, GetTextConvEx, RemoveAllConversions, RemoveConversion, SetFormulaConv, SetRationalConv, SetTableConv, SetTextConv, SetTextConvEx.
- Treated as renames, not gaps: RemoveParametersFromUnlockList is RemoveParameterFromUnlockList; GetVirtualParamCountGroup is GetVirtualParameterCountGroup; GetAppsHoldingMeasurementParameterMeasurementParameter (CHM typo) is GetAppsHoldingMeasurementParameter. Differences in case only (SetLiveupdates, CanConfigLoad, MatLabMExport and so on) were ignored.
- There are no site-only methods apart from these renames.
