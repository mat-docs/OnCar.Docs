## OBSOLETE

- **hardware/changing-the-pcmcia-card-slot-for-the-ca-card.md**. The page is a registry procedure for the `Ca125` kernel-driver service. Evidence:
    - The shipped driver `ThirdParty/CaCard/cacard.sys` is a 32-bit (i386, subsystem 4.00) NT kernel driver. It cannot load on the 64-bit Windows the installer now requires (`Bundle.wxs` chains the x64 .NET 8 runtimes).
    - The installer only copies `cacard.sys`; there is no `ServiceInstall` (`Product.wxs:318-320`), so the `Services\Ca125` key is never created.
    - The driver source `Core/CA125` (VC6 `.dsp`) is not in `SM.sln`.
