## Needs SME

2. **Shift-light semantics**: SM only stores the targets and offsets. The PCU firmware evaluates them, and that code is not in this repo. Please confirm that each light comes on at "Target RPM minus offset" (CHM example kept) and what the **Override Parameter** does.
3. **LED Action**: the CHM says it "flashes" the alarm LED. SM only passes the parameter and thresholds (`TPCUViewDefn.cpp:870-880`), so the firmware decides. Please confirm.
4. **Product status**: is the PCU-400 still a supported product? The whole section is gated to PCU400 projects.
